# Tutorials and Learning Resources

## 1. Hugging Face Agents Course
Covers agent fundamentals, tools, the Thought-Action-Observation loop, smolagents, LlamaIndex, LangGraph, evaluation, and a GAIA-based final project.  
https://huggingface.co/learn/agents-course/en/unit0/introduction

## 2. LangGraph Documentation
Official documentation for state graphs, loops, persistence, streaming, durable execution, and human-in-the-loop agent orchestration.  
https://docs.langchain.com/oss/python/langgraph/overview

## 3. AutoGen Documentation
Official documentation for building multi-agent applications, code execution, model clients, and orchestration patterns.  
https://microsoft.github.io/autogen/

## 4. CrewAI Documentation
Official learning material for agents, crews, tasks, flows, memory, knowledge, guardrails, and resumable long-running workflows.  
https://docs.crewai.com/

## 5. smolagents Documentation
Official guides and API references for code agents, tool calling, multi-step execution, memory, RAG, browser agents, and human-in-the-loop control.  
https://huggingface.co/docs/smolagents/

## Additional Research Reading
