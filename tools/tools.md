# Tools and Libraries

## LangGraph
A low-level orchestration framework for long-running, stateful agents. Its documentation emphasizes durable execution, persistence, branching, streaming, and human-in-the-loop workflows.  
[Official docs](https://docs.langchain.com/oss/python/langgraph/overview) · [GitHub](https://github.com/langchain-ai/langgraph)

## AutoGen
An open-source framework for multi-agent applications in which agents can converse and combine natural language, code, tools, and human participation.  
[Official docs](https://microsoft.github.io/autogen/) · [GitHub](https://github.com/microsoft/autogen)

## LlamaIndex
An open-source framework for agentic applications, especially useful when agents need to ingest, retrieve, organize, and reason over external data.  
[Official docs](https://developers.llamaindex.ai/) · [GitHub](https://github.com/run-llama/llama_index)

## CrewAI
A framework for collaborative agents, crews, and flows with support for memory, knowledge, guardrails, observability, and resumable workflow patterns.  
[Official docs](https://docs.crewai.com/) · [GitHub](https://github.com/crewAIInc/crewAI)

## smolagents
A lightweight Hugging Face library for multi-step agents. It provides code agents and tool-calling agents, with examples covering memory, RAG, browser agents, and human-in-the-loop execution.  
[Official docs](https://huggingface.co/docs/smolagents/) · [GitHub](https://github.com/huggingface/smolagents)
