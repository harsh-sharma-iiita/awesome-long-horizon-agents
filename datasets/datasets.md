# Benchmarks and Datasets

These resources meet the assignment's requirement for at least three dataset/benchmark resources. They are selected because long-horizon agents must be evaluated through interactive tasks rather than only static generation quality.

## 1. WebArena

**Source:** WebArena project / ICLR 2024 paper  
**Description:** A realistic, reproducible web environment with fully functional sites covering e-commerce, social forums, collaborative software development, and content management. The benchmark emphasizes functional correctness on diverse, long-horizon internet tasks.  
**Application:** Browser agents, planning, tool use, state tracking, recovery, web navigation.  
**Links:** [Project](https://webarena.dev/) · [Code](https://github.com/web-arena-x/webarena) · [Paper](https://arxiv.org/abs/2307.13854)

## 2. MLE-bench

**Source:** OpenAI / ICLR 2025  
**Description:** A benchmark built from 75 Kaggle machine-learning competitions, covering dataset preparation, model training, experimentation, and submission-oriented engineering.  
**Application:** Long-horizon ML engineering, code execution, experiment iteration, resource-aware agent evaluation.  
**Links:** [Paper](https://arxiv.org/abs/2410.07095) · [Code](https://github.com/openai/mle-bench)

## 3. TheAgentCompany

**Source:** Carnegie Mellon University and collaborators  
**Description:** A self-contained simulated software company with websites, data, communication, and professional tasks designed for computer-using agents.  
**Application:** Digital-worker agents, consequential tool use, workplace planning, multi-step execution.  
**Links:** [Project](https://the-agent-company.com/) · [Code](https://github.com/TheAgentCompany/TheAgentCompany) · [Paper](https://arxiv.org/abs/2412.14161)

## 4. GAIA

**Source:** Mialon et al.  
**Description:** A benchmark for general assistants requiring combinations of reasoning, multimodality, web browsing, and tool use.  
**Application:** General-purpose assistants and multi-step tool-use evaluation.  
**Links:** [Benchmark](https://huggingface.co/gaia-benchmark) · [Paper](https://arxiv.org/abs/2311.12983)
