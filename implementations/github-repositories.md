# GitHub Implementations

The repositories below were selected based on direct connection to a research paper or benchmark, documentation/source availability, and relevance to long-horizon agent construction.

1. **Reflexion** — Official implementation of verbal reinforcement learning with reflective memory.  
   https://github.com/noahshinn024/reflexion

2. **Language Agent Tree Search (LATS)** — Implementation of tree search for reasoning, acting, planning, value estimation, and self-reflection.  
   https://github.com/lapisrocks/LanguageAgentTreeSearch

3. **Tree of Thoughts** — Code and prompts for tree-structured deliberate reasoning and search.  
   https://github.com/princeton-nlp/tree-of-thought-llm

4. **SWE-agent** — Autonomous software-engineering agent using a specialized agent-computer interface.  
   https://github.com/SWE-agent/SWE-agent

5. **OpenHands** — Open platform for coding, terminal interaction, browsing, sandboxes, and agent evaluation.  
   https://github.com/All-Hands-AI/OpenHands

6. **WebArena** — Reproducible environment and evaluation harness for realistic browser agents.  
   https://github.com/web-arena-x/webarena

7. **MLE-bench** — Benchmark and evaluation code for machine-learning engineering agents.  
   https://github.com/openai/mle-bench
